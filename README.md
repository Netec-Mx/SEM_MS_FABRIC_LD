# Introducción a Microsoft Fabric

Los participantes conocerán los fundamentos de Microsoft Fabric y comprenderán cómo esta plataforma integra el almacenamiento, la ingeniería de datos, el análisis, la inteligencia empresarial y la inteligencia artificial dentro de un ecosistema unificado. Asimismo, explorarán sus principales componentes y conocerán el flujo básico para desarrollar proyectos analíticos utilizando Microsoft Fabric.

## Estructura

- `CapituloXX/README.md`: guía de laboratorio por capítulo.

## Lista de laboratorios

### Capítulo 1

- [El instructor realizará un recorrido por la interfaz de Microsoft Fabric, mostrando la organización de los espacios de trabajo, la navegación entre sus principales experiencias y la forma en que OneLake centraliza el almacenamiento de información para distintos escenarios analíticos.](Capitulo01/README.md#el-instructor-realizará-un-recorrido-por-la-interfaz-de-microsoft-fabric-mostrando-la-organización-de-los-espacios-de-trabajo-la-navegación-entre-sus-principales-experiencias-y-la-forma-en-que-onelake-centraliza-el-almacenamiento-de-información-para-distintos-escenarios-analíticos)
  - Descripción: Recorrido demostrativo por la interfaz de Microsoft Fabric para reconocer la organización de los espacios de trabajo, navegar entre sus principales experiencias y observar cómo OneLake centraliza el almacenamiento de información para distintos escenarios analíticos.
  - Duración estimada: 30 min

### Capítulo 2

- [El instructor mostrará un flujo de trabajo básico utilizando Microsoft Fabric, ilustrando cómo conectar una fuente de datos, preparar información, explorarla mediante una experiencia analítica y visualizar los resultados en un reporte de Power BI. Asimismo, realizará una breve demostración de las capacidades de Microsoft Copilot para asistir en la generación de consultas, transformaciones y análisis de datos dentro de la plataforma.](Capitulo02/README.md#el-instructor-mostrará-un-flujo-de-trabajo-básico-utilizando-microsoft-fabric-ilustrando-cómo-conectar-una-fuente-de-datos-preparar-información-explorarla-mediante-una-experiencia-analítica-y-visualizar-los-resultados-en-un-reporte-de-power-bi-asimismo-realizará-una-breve-demostración-de-las-capacidades-de-microsoft-copilot-para-asistir-en-la-generación-de-consultas-transformaciones-y-análisis-de-datos-dentro-de-la-plataforma)
  - Descripción: Demostración de un flujo de trabajo básico en Microsoft Fabric para conectar una fuente de datos, preparar y explorar la información, visualizar resultados en un reporte de Power BI y observar el uso de Microsoft Copilot como apoyo en la generación de consultas, transformaciones y análisis de datos.
  - Duración estimada: 30 min
